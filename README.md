# 🛍️ My Shopping App

A beginner-friendly Vue.js shopping app . This project demonstrates Vue components, event handling, and a simple cart system.

## 🚀 Features

- Product listing with price
- Add to cart functionality
- Cart display with product names and prices

## 🛠️ Tech Stack

- Vue.js 2 (via Vue CLI)
- JavaScript
- HTML & CSS
